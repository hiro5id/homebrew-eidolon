Eidolon for Homebrew
===

The Homebrew tap of [Eidolon](https://github.com/hiro5id/eidolon-releases). Find duplicate photos and videos by how they look, and export one clean library. macOS and Linux, Apple Silicon, Intel and ARM. Latest version: 2026.11.4.

```sh
brew tap hiro5id/eidolon                 # once: add this tap
brew install eidolon                     # install
eidolon                                  # start it: its window opens (Open shows the review screen)
brew update && brew upgrade eidolon      # update (or Update now on the review screen)
brew uninstall eidolon && brew untap hiro5id/eidolon   # remove
```

Each release updates `Formula/eidolon.rb` here by itself: don't edit it by hand. Other ways to install, and every release: [hiro5id/eidolon-releases](https://github.com/hiro5id/eidolon-releases).
